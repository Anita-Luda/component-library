1. ATOMY (124+ TAGI HTML5 + WARIANTY)
--------------------------------------------------------------------------------
Każdy atom w każdym stanie i typie istnieje jako fizyczny fragment w lib/catalog/*.html.
Nie ma żadnego fallbacku na generowanie HTML przez JavaScript.

Główne Atomy Interaktywne (7 stanów x Typy):
- Button (Primary, Secondary, Tertiary, Default) | [D][H][F][A][X][E][S] | OK (Fizyczny)
- Icon Button (Primary, Secondary, Tertiary)    | [D][H][F][A][X][E][S] | OK (Fizyczny)
- Input (Default, Primary, Secondary)           | [D][H][F][A][X][E][S] | OK (Fizyczny)
- Textarea (Default)                            | [D][H][F][X]          | OK (Fizyczny)
- Select (Default)                              | [D][X]                | OK (Fizyczny)
- Toggle (Default)                              | [D][X]                | OK (Fizyczny)
- Range (Default)                               | [D][X]                | OK (Fizyczny)
- Radio (Default)                               | [D][H][F][A][X][E][S] | OK (Fizyczny)
- Checkbox (Default)                            | [D][H][F][A][X][E][S] | OK (Fizyczny)

Atomy Typograficzne i Inne (Stan Default):
- Tagi H1-H6, P, Span, Overline, Badge, Avatar  | [D]                   | OK (Fizyczny)
- Wszystkie pozostałe tagi HTML5 (np. abbr, address, canvas, code, details, dialog, footer, main, nav, section, table, video itp.) | [D] | OK (Fizyczny)

Uzasadnienie stanów:
- Komponenty statyczne (np. <p>, <address>) posiadają tylko stan 'Default', ponieważ natywne przeglądarki nie definiują dla nich stanów interaktywnych takich jak 'Focus' czy 'Active' w kontekście formularzy.
